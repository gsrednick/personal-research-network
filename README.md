# Research network — GitHub Pages

Upload `index.html` and the `assets` folder to the root of `gsrednick/personal-research-network`.

## Add images
Place your own JPEG/PNG/WebP files in `assets/images/` and animated GIF files in `assets/gifs/`. Match the filenames referenced in the `media` arrays inside `index.html`, or edit those paths.

Suggested image names:
- research-overview.jpg
- asynchrony.jpg
- equilibrium.jpg
- spatial-resilience.jpg
- advanced-sensing.jpg
- environmental-variability.jpg
- species-interactions.jpg
- larval-connectivity.jpg
- biophysical-modeling.jpg
- field-ecology.jpg

Suggested GIF names:
- asynchrony.gif
- coral-settlement.gif
- dispersal.gif

Missing files are hidden automatically. Use optimized images (typically < 500 KB each). GitHub Pages paths are case-sensitive. A transparent iframe background requires the parent Squarespace page and iframe styling to permit transparency.

The research descriptions are adapted from the user's public research page and extended for the additional methods and mechanisms. Review text and product links before publishing.
